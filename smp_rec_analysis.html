Day 6 포스팅에 중대한 계산 오류 발견
REC 단가를 원/kWh로 잘못 적용하였습니다. REC 가격의 단위는 원/REC = 원/MWh = 원/1,000kWh입니다. 42원/kWh로 계산한 기존 방식은 실제 수익을 약 40~50% 과소 계상한 수치입니다.
✅
올바른 REC kWh 환산 공식
kWh당 REC 수익 = REC 현물단가(원/REC) × 가중치 ÷ 1,000
예) 70,000원/REC × 1.2 ÷ 1,000 = 84원/kWh
⚠️
합산 단가 수정 필요
기존 포스팅 합산단가 160~180원/kWh → 수정 후 보수적 188원 / 기본 224원/kWh으로 상향 조정 필요

03 REC 단가 계산 방법 — 오류 원인 분석
📐
REC 기본 개념
1 REC = 발전량(MWh) × 가중치 → 1,000 kWh 기준으로 발급
예) 가중치 1.2 발전소가 1,000 kWh 발전 → 1.2 REC 발급 (출처: 무한에너지, 아진솔라텍)
/* ❌ Day 6 기존 계산 (오류) */ REC 42원/kWh × 1.2 = 50원/kWh ← 단위 오류. REC는 원/kWh가 아닌 원/REC(=원/MWh) /* ✅ 올바른 계산 방법 */ kWh당 REC 수익 = REC 현물단가(원/REC) × 가중치 ÷ 1,000(kWh/MWh) /* 2024년 기본 시나리오 */ = 76,179원/REC × 1.2 ÷ 1,000 = 91원/kWh /* 보수적 시나리오 (2025년 하락 반영) */ = 65,000원/REC × 1.2 ÷ 1,000 = 78원/kWh

05 Day 6 수익 재계산 — 99kW, 전라남도 기준
/* 기본 조건: 99kW / 전라남도 / 일평균 3.8h / PR 0.87 */ 연간 발전량 = 99kW × 3.8h × 365일 × 0.87 = 119,462 kWh /* ─── 보수적 시나리오 (188원/kWh) ─── */ 연간 발전 수익 = 119,462 × 188 = 22,459,000원 (약 2,246만원) 연간 비용 합계 = 10,280,000원 (이자+임대료+운영+보험+유지+세무+예비) 연간 순수익 = 약 1,218만원 → 월 약 101만원 /* ─── 기본 시나리오 (214원/kWh) ─── */ 연간 발전 수익 = 119,462 × 214 = 25,565,000원 (약 2,557만원) 연간 비용 합계 = 10,280,000원 연간 순수익 = 약 1,528만원 → 월 약 127만원 /* ─── 낙관적 시나리오 (246원/kWh) ─── */ 연간 발전 수익 = 119,462 × 246 = 29,388,000원 (약 2,939만원) 연간 비용 합계 = 10,280,000원 연간 순수익 = 약 1,911만원 → 월 약 159만원

06 2025년 현재 — 투자자가 반드시 알아야 할 리스크
  • 📉
    SMP 하락 추세 지속 — 2025년 SMP는 70원대 후반에서 120원대까지 큰 편차를 보이고 있으며, 2022년 에너지 위기 이전(100원 미만) 수준으로 회귀 우려가 있습니다. 사업성 검토 시 보수적 기준 110원/kWh 적용을 권장합니다.
  • 📦
    국가 REC 방출로 REC 하락 위험 — 2023년 11월 도입된 국가 REC 제도로 정부가 현물시장에 REC를 공급하면 가격이 급락합니다. 2025년 하반기에도 추가 방출 가능성이 있습니다.
  • ⚡
    태양광 공급 과잉 — 태양광 신규 설치 용량이 원자력보다 100배 빠르게 증가하면서 SMP 형성에 불리한 구조가 만들어지고 있습니다. 이는 장기적 SMP 하락 압력 요인입니다.
  • 🌍
    국제유가 연동 리스크 — SMP는 LNG 가격에 4~5개월 시차를 두고 연동됩니다. 유가 급락 시 SMP도 동반 하락합니다. 두바이유 동향을 주기적으로 모니터링해야 합니다.
  • 📊
    실시간 단가 확인 필수 — 투자 결정 전 반드시 최신 단가를 직접 확인하세요. 확인 경로: 전력거래소 EPSIS(epsis.kpx.or.kr) / 엔라이튼 시장동향 / 한전 월가중평균 SMP
